# VRChat Dictionary Preview

VRChatに関する項目を検索・閲覧する非公式の辞典プレビューです。

## 機能

- 見出し・別名・タグの部分一致による入力候補
- 本文検索、カテゴリ絞り込み、50件単位のページ表示
- 辞典ID付きの記事、公開・実施日時、複数の参照URL
- 年別の一覧
- ブラウザー内での編集提案・承認、CSV/JSONの取込・書き出し

編集提案は利用中のブラウザー内だけに保存されます。共有編集、アカウント認証、Google Sheets自動同期は未実装です。日付別一覧は辞典の公開・実施日時を使用し、年表の全出来事を再現するものではありません。

## 開発

Node.js 22以降で実行できます。依存パッケージのインストールは不要です。

```sh
npm test
npm run build
```

標準ビルドは架空のサンプルを使用します。実際の表示用スナップショットでビルドする場合は、DICTIONARY_DATA_FILEにJSONファイルのパスを指定してください。dist/を静的サーバーで配信します。

## 公開とデータ管理

公開用の画面コードとサンプルのみをGitで管理します。元のGoogle Sheets、内部管理列、認証情報、データベース、実データのJSONは含めません。GitHub Actionsで公開用スナップショットを復元してPagesへ配信します。表示されるデータは公開サイトから取得可能です。

公開データはスナップショットです。シートの変更は自動反映されません。管理者はscripts/upload-snapshot.pyで公開するJSONを差し替え、Publish dictionary previewを実行できます。アップロードにはPythonのPyNaClと、GitHubの対象リポジトリを管理できる既存のGit認証を使用します。

```sh
python scripts/upload-snapshot.py private-data/snapshot.json
```

元シートの公開設定は変更しません。VRChatおよび各掲載対象の公式サイトではありません。各名称・記事・参照先に関する権利はそれぞれの権利者に帰属します。
